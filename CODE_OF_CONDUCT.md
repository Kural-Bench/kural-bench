# Code of conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

- Be respectful. Disagree with results and arguments, not with people.
- Back claims about a score with the score report and the predictions file.
- No harassment, insults or personal attacks in issues, pull requests or discussions.

The maintainer may edit or remove comments, issues and pull requests that break these rules, and may block anyone who breaks them repeatedly. Report a conduct problem privately through the contact details at https://ashwingopalsamy.in.
